# How to engage with Cameraderie Cards™

This repository is a **public landing page and feedback hub** for the
Cameraderie Cards web app at [cameraderiecards.com](https://cameraderiecards.com).
The actual app source code is proprietary and not publicly distributed.

That means this isn't a "send a pull request to add a feature" kind of
repo. It's a place to:

- **Report bugs** you hit while using the app
- **Request features** you'd like to see
- **Discuss MTG, collecting, and the app** in the [Discussions](../../discussions) tab
- **Help polish the public docs** (typos, broken links, fresher screenshots)

---

## Ways to engage

### 🐛 Bug reports

Use the [**Bug report** template](../../issues/new?template=bug.yml).
The template asks for:

- A short title describing what went wrong
- Steps to reproduce
- What you expected vs. what actually happened
- Browser + operating system
- (Optional) Your tier — Free, Pro Monthly, or Lifetime

The more detail you give, the faster it gets fixed.

### ✨ Feature requests

Use the [**Feature request** template](../../issues/new?template=feature.yml).
Tell us:

- What you want the app to do
- Why — what problem does it solve for you?
- Where in the app it would live (a new dashboard card? a setting?)
- A mockup or sketch if you have one (optional but appreciated)

A lot of the roadmap comes straight from this tab. Don't be shy.

### 💬 Discussions

For open-ended conversation — favorite cards, how you organize your
binders, "is this a hot take?" — head to the [Discussions](../../discussions)
tab. No template, no pressure.

---

## What this repo accepts as Pull Requests

We accept PRs for the **public-facing content of this repository**:

- ✅ Typo / grammar fixes in README, CONTRIBUTING, CHANGELOG, or
  issue templates
- ✅ Fixing broken links
- ✅ Updated screenshots when the app's look has changed and the old
  shots are stale (please match the same scene / page as the existing
  shot you're replacing)

We do **not** accept:

- ❌ App source code — the source isn't here. Feature ideas go through
  Issues, where they're triaged and implemented privately.
- ❌ Branding, logo, or trademark changes
- ❌ License changes
- ❌ Anything that conflicts with the project's commercial direction

---

## Code of conduct

Be decent. The Cameraderie Cards community is small, friendly, and
collector-first. We have zero tolerance for harassment, slurs, or
bad-faith arguing. Issues and discussions that violate that bar get
locked or removed without ceremony.
